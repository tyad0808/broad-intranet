# 화면 디자인

- 글꼴 Pretendard. 바탕은 흰색·회색, **포인트 색은 클래식 블루(`--primary`)** 만. 색은 `:root` 변수로만 정한다.
- **글자는 최소 14px**, 버튼·선택 칸은 PC 36~40px, 휴대폰 44px 이상. 휴대폰(390px)에서도 깨지지 않게.
- 주문 상태 배지(`.st-badge` + `sb-*`): 신규=파랑, **작업 중=주황(여기서만 주황 허용)**, 발송 준비=보라, 완료=초록, 입금대기=회색, 취소=빨강.
- 빈 화면·오류 화면·불러오는 중은 친절한 문구 + 다음에 할 일 버튼으로.
- 반투명 유리 효과는 **떠 있는 것만** (위쪽 머리 `.sticky-glass`, 아래 처리 막대). 배경 그라데이션·테두리 없는 그림자·알약 모양 전체 적용은 **사용자가 싫다고 해서 되돌렸다** — 다시 하지 않는다.
- 기능·주소·보내는 값은 바꾸지 않고 모양만 바꾼다. 큰 디자인 변경 전에는 백업 브랜치를 남긴다 (`backup-before-design` 이 디자인 리뉴얼 전 상태).
- 바꾼 화면은 Playwright 로 PC(1280·1440)와 휴대폰(390) 캡처를 찍어 직접 확인한 뒤 보낸다. 브라우저: `/opt/pw-browsers/chromium`.
- CSP 때문에 **인라인 스크립트 금지** — 스크립트는 `public/*.js` 파일로.

## 새 디자인 규칙 (2026-10, ui-ux-pro-max 점검 · `body.ds-v2`)

인쇄업체 사내 주문관리, 직원이 하루 종일 보는 화면 → **깔끔·정보 위주·크게**. 지금은 주문 목록에만 켜져 있고(`ds: true`), 확인받은 뒤 모든 화면으로 넓힌다. 스킬 추천 중 청록·주황 색, 영문 글꼴, 스크롤 애니메이션은 회사 규칙과 맞지 않아 쓰지 않는다.

- **색**: 파랑 `#2563EB` 하나만 포인트. 흐린 글자 `--muted: #6B7684` (흰 바탕 대비 4.5 이상). 글자 대비는 늘 4.5:1 이상.
- **상태 배지**: 색 + 점 + 글자 (색만으로 구분하지 않는다). 신규=파랑, 작업 중=주황, 발송 준비=보라 `#5B3CC4`, 완료=초록 `#067A52`, 입금대기=회색, 취소=빨강 `#C81E2F`.
- **글자 크기는 5단계만**: 14(날짜·설명) · 16(본문) · 18(소제목·상품 이름) · 22(카드 제목) · 28(화면 제목). 14px 미만 금지. 숫자는 `tabular-nums`.
- **버튼 3종**: 주요(파랑 채움, 한 칸에 하나만) · 보조(흰 바탕 + 파란 테두리) · 위험(빨강, 늘 확인창). 크기 PC 44px(작은 버튼 40px), 휴대폰 48px. 버튼 글자 15~16px. 자주 쓰는 처리 버튼은 늘 같은 순서·같은 자리 (발주확인 → 로젠 등록 → 송장·발송처리 → 발주서 출력).
- 몇 초 걸리는 버튼은 누르면 바로 잠그고 돌아가는 표시(`data-once` → `.busy`). 못 누르는 버튼은 이유를 한 줄 보여 준다.
- **아이콘은 선 SVG** (이모지 대신 — 컴퓨터마다 모양이 다름). 아이콘만 있는 버튼에는 `aria-label`.
- 장식 없음: 그림자 아주 옅게, 모서리 8/12px, 움직임은 색 바뀜 정도(0.15초 이하).
