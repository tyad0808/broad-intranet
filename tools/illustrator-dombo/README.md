# 일러스트레이터 브로애드 도구 패널 (돔보마크 · 칼선 · 격자 칼선 · 막대 + 박스 · 아일렛 · 분할 · 치수 표시 · 개수 세기 · 크기·헤베 · 넘버링)

그라프텍 Cutting Master 5 처럼 일러스트레이터 안에서 **평판 커팅기용 원형 돔보마크**를 찍는 패널입니다.
출력 → 커팅기 카메라가 마크를 읽고 → 칼선대로 자르는 작업(인쇄 후 커팅)에 씁니다.

## 기능

| 버튼 | 하는 일 |
|---|---|
| **돔보 찍기** | 선택한 작업물 둘레에 원형 마크를 찍습니다. 아무것도 선택하지 않으면 문서의 보이는 개체 전체를 기준으로 합니다 (대지 밖 개체도 포함, 숨긴 레이어·개체, 안내선, 돔보·칼선 레이어는 뺌). '현재 대지' 를 고르면 대지 테두리 기준. `돔보마크` 레이어에 먹 100% 로 만들고 잠급니다. 다시 누르면 기존 마크를 지우고 새로 찍습니다. |
| **돔보 지우기** | `돔보마크` 레이어를 지웁니다. |
| **번호 붙이기** (넘버링 칸) | 출력물을 전부 선택하고 누르면 **줄마다 왼쪽 → 오른쪽, 위 줄 → 아래 줄** 순서로 `1, 2, 3 …` 번호를 `넘버링` 레이어에 먹 100% 로 씁니다. 높이가 달라도 세로로 반 이상 겹치면 같은 줄로 봅니다. **조각 번호까지**를 켜면 작업물 안에 조각이 여러 개일 때 `3-1, 3-2 …` 도 같은 순서로 (클리핑 마스크는 안쪽 내용, 선·1mm 보다 가는 것은 조각이 아님). **앞 글자**(예: `1028-`)를 넣으면 번호 앞에 붙습니다. 번호는 출력되지 않게 **늘 작업물 바깥**에 놓습니다: 작업물 번호는 **우측 상단 바깥**(기준: 맨 바깥 클리핑 마스크 > 그룹 > 가장 큰 개체), 조각 번호는 그 조각이 닿은 작업물 가장자리 바깥(윗줄은 위, 아랫줄은 아래, 가운데 줄은 왼쪽·오른쪽). 글자 크기는 **실제 크기 기준 mm**(기본 5mm), **1:1 / 10:1** 을 고르면 10:1 파일에선 1/10 로 씁니다. **지우기**는 `넘버링` 레이어를 지웁니다. 고르는 법은 사이즈 표시와 같습니다. |
| **크기·헤베** (따로 된 칸) | 선택한 작업물의 **실제 가로·세로(mm)** 와 **헤베(㎡, 소수 2자리)** 를 알려 줍니다. **1:1** / **10:1**(1/10 로 그린 파일, ×10)을 고릅니다. 기준은 **맨 바깥 클리핑 마스크 > 그룹 > 선택한 것 중 가장 큰 개체** 순서 (같은 순위가 여럿이면 가장 큰 것), 패스 기준(선 두께 제외). 큰 캔버스 문서도 맞게 잽니다. 무엇을 기준으로 쟀는지 함께 보여 줍니다. |
| **사이즈 표시** (크기·헤베 칸) | 작업물마다 위쪽에 `103*105cm(가로*세로)` 글자를 `사이즈` 레이어에 먹 100% 로 씁니다. 1:1 / 10:1 은 크기·헤베와 같이 고르고, 글자 크기는 **실제 크기 기준 mm**(기본 40mm, 10:1 파일이면 1/10 인 4mm 로). 여러 개를 고르면 고른 것마다(그룹이든 패스든), 그룹 하나만 고르면 안에 하위 그룹이 있을 때 안의 것마다. 작업물 안의 기준은 맨 바깥 클리핑 마스크 > 그룹 > 가장 큰 개체 (패스 기준). 한글이 나오는 글꼴(맑은 고딕 등)이 있으면 그걸 씁니다. **지우기**는 `사이즈` 레이어를 지웁니다. |
| **칼선** (칼선 · 도련 칸) | 작업물마다 칼선 **하나**를 `칼선` 레이어에 `CutContour` 별색 0.25pt 선으로 만듭니다. 기준은 **맨 바깥 클리핑 마스크**(마스크 모양) > **그룹**(안의 도형을 패스파인더 합치기로 합친 외곽선 하나) > **개체 모양**. 살아있는 글자는 아웃라인, 이미지는 뺍니다. 여러 개면 고른 것마다, 그룹 하나에 하위 그룹이 있으면 안의 것마다. |
| **도련 (원본) / 도련 (마스크)** (칼선 · 도련 칸) | 원본은 그대로 두고, 복제본(`도련`)을 **원본 바로 아래**에 놓아 사방 N mm(기본 3mm, 파일 크기 그대로) 키웁니다. **(원본)** 은 복제본 전체를 가로·세로로 키우고, **(마스크)** 는 맨 바깥 클리핑 마스크만 키워 가려졌던 그림이 보이게 합니다 (마스크가 없는 것은 원본 방식으로). |
| **선택한 사각형 → 격자 칼선** | 선택한 사각형(그룹 안까지)의 모든 변 위치에 전체 영역을 가로지르는 `CutContour` 선을 긋습니다. 왼쪽 위에서 시작해 칼이 빈 채로 움직이는 거리가 짧도록 순서와 방향(지그재그)을 정해 `칼선` 레이어에 쌓습니다 (맨 아래가 첫 번째). 0.1mm 안으로 붙은 변은 하나로 합칩니다. '기준 사각형 지우기' 를 끄면 사각형을 남깁니다. |
| **막대 + 박스 만들기** | 객체 위쪽으로 '막대 간격' 만큼 띄워 객체와 같은 가로 길이의 먹 100% 막대를 만들고, 객체 + 막대를 '박스 여백' 만큼 감싸는 사각 박스(검정 1pt, 또는 CutContour 칼선)를 그립니다. 여러 개를 선택하면 각각, 그룹 하나를 선택하면 안의 하위 그룹마다 (하위 그룹이 없으면 그룹 전체) 만듭니다. 지금 레이어에 만듭니다. 같은 칸에 **글자·도형 개수 세기** 버튼이 있습니다. |
| **아일렛 표시** | 현수막 등 타공 자리를 원으로 표시합니다. 위·아래·왼쪽·오른쪽 개수(모서리 포함, 1개면 가운데)를 따로 넣고, 원 **바깥선**이 테두리에서 '외곽 여백' 만큼 떨어지게 찍습니다 (중심은 여백 + 반지름 안쪽). 모서리처럼 겹치는 자리는 하나만, 여러 개를 선택해도 같은 자리는 한 번만. 클리핑 마스크는 마스크 모양 기준. `아일렛` 레이어에 먹 100% 선(기본 1pt)으로 그리고, **아일렛 지우기**로 지웁니다. |
| **분할하기** | 큰 현수막·실사를 출력 폭에 맞게 N등분합니다. **가로 분할**(좌우로) / **세로 분할**(위아래로), 개수, 겹침(이음매마다 양쪽 합계, 기본 20mm). 클리핑 마스크는 보이는 영역(마스크) 기준으로 나눕니다. 원본은 그대로 두고, 조각마다 원본을 복제해 사각형 클리핑 마스크를 씌워 `분할` 레이어의 원본 아래 50mm 부터 늘어놓습니다 (`분할 1/3` …). 클립보드는 쓰지 않습니다. |
| **치수 표시** | 선택한 객체마다(또는 전체를 하나로) 가로·세로 치수선과 글자(예: `1,200 mm`)를 `치수` 레이어에 파랑으로 그립니다. 가로는 위/아래, 세로는 오른쪽/왼쪽, 치수선 거리, 글자 크기(자동: 큰 변의 3%, 2.5~60mm), 소수점, 'mm' 표시를 고릅니다. 기본은 패스 크기(선 두께 제외)로 재고, 클리핑 마스크는 마스크 모양 기준입니다. **치수 지우기**는 `치수` 레이어를 지웁니다. 출력·커팅할 땐 레이어를 숨기세요. |
| **글자·도형 개수 세기** (막대 + 박스 칸) | 선택한 것(없으면 문서 전체)의 살아있는 글자 수(공백 포함/제외)와 아웃라인 도형 수를 셉니다. 그룹 안까지 세고, 클리핑 마스크 틀·숨긴 개체는 뺍니다. |

칸마다 자주 쓰는 버튼만 보이고, 입력칸은 **설정 ▸** 을 눌러야 펼쳐집니다. 접혀 있어도 지금 값이 한 줄로 보입니다 (예: `Ø6 · 거리 5 · 간격 300 · 방향점 50`). 값은 바꾸는 즉시 기억됩니다.
설명 글은 위쪽 **도움말** 을 눌렀을 때만 보입니다.

패널 위쪽 **순서·이름** 을 누르면 칸의 순서(▲▼)와 이름을 바꿀 수 있습니다. 바꾼 순서·이름과 칸을 접은 상태는 그 컴퓨터에 기억되고, **처음대로** 로 되돌릴 수 있습니다.

설정

| 항목 | 기본값 | 뜻 |
|---|---|---|
| 마크 지름 | 6mm | 원형 마크 크기 |
| 작업물과의 거리 | 5mm | 선택한 작업물 테두리(선 두께 포함)부터 **마크 가장자리**까지. 클리핑 마스크는 가려진 부분을 빼고 마스크 모양 기준 |
| 마크 간격 (최대) | 300mm | 위·아래 변의 **마크 중심** 사이 간격. 네 모서리에는 항상 찍고, 위·아래 변을 이 값을 넘지 않게 똑같이 나눕니다. 왼쪽·오른쪽 변 가운데에는 찍지 않습니다. 0 이면 네 모서리만 |
| 방향 표시점 | 켬, 오른쪽 아래, 50mm | 좌우(방향)를 알 수 있게 고른 모서리 마크에서 가로 변을 따라 안쪽으로 그 거리(중심 사이)에 점을 하나 더 찍습니다 (`돔보_방향`). 다른 마크와 겹치면 알려 줍니다 |
| 대지 넓히기 / 여백 | 켬 / 5mm | 마크가 대지 밖으로 나가면 대지를 마크 바깥 여백까지 넓힙니다 |

예) 작업물 100 × 50mm, 거리 5mm, 지름 6mm 이면 마크 중심은 116 × 66mm 사각형의 둘레에 놓입니다.
간격 50mm 로 하면 위·아래 변이 3칸(38.7mm)으로 나뉘어 마크 8개가 찍히고, 실제 간격은 찍은 뒤 패널에 표시됩니다.

## 설치

일러스트레이터 CC 2017 이상 (윈도우·맥).

- 윈도우: `install-windows.bat` 더블클릭
- 맥: 터미널에서 `bash install-mac.sh`

일러스트레이터를 다시 켜고 **창 > 확장 > 브로애드 도구** 를 엽니다.
(사내용이라 어도비 서명을 하지 않았기 때문에, 설치 스크립트가 `PlayerDebugMode` 를 켜서 서명 없는 확장을 허용합니다.)

### 패널 없이 쓰기

`jsx` 폴더를 통째로 복사한 뒤, **파일 > 스크립트 > 기타 스크립트...** 에서 고릅니다.
`DomboMark.jsx`(돔보, 설정 창), `GridCut.jsx`(격자 칼선), `BarBox.jsx`(막대 + 박스, 설정 창), `Grommet.jsx`(아일렛, 설정 창), `Split.jsx`(분할, 설정 창), `Dimension.jsx`(치수 표시), `Count.jsx`(개수 세기), `Hebe.jsx`(크기·헤베), `Number.jsx`(넘버링).

## 커팅기에서 쓸 때 주의

- 커팅기 쪽(Cutting Master 또는 커팅기 본체) 마크 설정을 여기와 **같은 지름·거리·간격** 로 맞춰야 카메라가 읽습니다.
- 마크 주변은 비워 두세요. 마크 근처에 인쇄물이 있으면 카메라가 잘못 읽습니다.
- 커팅기로 칼선을 **보내는 기능은 없습니다.** 커팅기 드라이버(Cutting Master 등)로 보내거나, PDF 로 저장해 RIP 에서 `CutContour` 별색을 칼선으로 인식시키세요.
