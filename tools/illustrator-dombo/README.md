# 일러스트레이터 돔보마크 패널

그라프텍 Cutting Master 5 처럼 일러스트레이터 안에서 **돔보(레지스트레이션) 마크**를 찍는 패널입니다.
출력 → 커팅기 센서가 마크를 읽고 → 칼선대로 자르는 작업(인쇄 후 커팅)에 씁니다.

## 기능

| 버튼 | 하는 일 |
|---|---|
| **돔보 찍기** | 선택한 작업물(또는 현재 대지) 둘레에 마크를 찍습니다. `돔보마크` 레이어에 먹 100% 로 만들고 잠급니다. 다시 누르면 기존 마크를 지우고 새로 찍습니다. |
| **돔보 지우기** | `돔보마크` 레이어를 지웁니다. |
| **선택 → 칼선 만들기** | 선택한 패스를 복제해 `칼선` 레이어에 `CutContour` 별색 0.25pt 선으로 만듭니다. 원본은 그대로 둡니다. 글자는 먼저 윤곽선 만들기를 하세요. |

설정
- 마크 모양: L자(모서리) / 사각형
- 개수: 4점 / 3점(오른쪽 위 생략)
- 마크 크기, L자 선 두께, 작업물과의 거리 (mm)
- 마크가 대지 밖으로 나가면 대지를 마크 바깥 여백만큼 자동으로 넓히기

마크의 **바깥 모서리**가 `작업물 범위 + 거리` 사각형의 꼭짓점에 정확히 놓입니다.

## 설치

일러스트레이터 CC 2017 이상 (윈도우·맥).

- 윈도우: `install-windows.bat` 더블클릭
- 맥: 터미널에서 `bash install-mac.sh`

일러스트레이터를 다시 켜고 **창 > 확장 > 돔보마크** 를 엽니다.
(사내용이라 어도비 서명을 하지 않았기 때문에, 설치 스크립트가 `PlayerDebugMode` 를 켜서 서명 없는 확장을 허용합니다.)

### 패널 없이 쓰기

`jsx` 폴더의 두 파일을 함께 복사한 뒤, **파일 > 스크립트 > 기타 스크립트...** 에서 `DomboMark.jsx` 를 고르면 같은 설정 창이 뜹니다.

## 커팅기에서 쓸 때 주의

- 커팅기 쪽(Cutting Master 또는 커팅기 본체) 마크 설정을 여기와 **같은 모양·개수·크기·거리** 로 맞춰야 센서가 읽습니다.
- 마크 주변은 비워 두세요. 마크 근처에 인쇄물이 있으면 센서가 잘못 읽습니다.
- 커팅기로 칼선을 **보내는 기능은 없습니다.** 커팅기 드라이버(Cutting Master 등)로 보내거나, PDF 로 저장해 RIP 에서 `CutContour` 별색을 칼선으로 인식시키세요.

## 파일

| 파일 | 내용 |
|---|---|
| `CSXS/manifest.xml` | 패널 등록 정보 |
| `index.html`, `panel.js` | 패널 화면 |
| `jsx/dombo-core.jsx` | 마크 계산과 그리기 (패널·단독 스크립트 공용) |
| `jsx/DomboMark.jsx` | 패널 없이 쓰는 단독 스크립트 |

마크 좌표 계산은 `test/dombo.test.js` 에서 검사합니다 (`npm test`).
