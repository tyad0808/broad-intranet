# 브로애드 파일 받기 (NAS → 출력 컴퓨터)

NAS 의 기계별 폴더에 파일을 올리면, 그 기계의 출력 컴퓨터가 **자동으로 복사해 오고**, **목록**에 띄우고, **알림·소리**로 알려 주는 윈도우 프로그램입니다.

```
디자이너 PC ──(탐색기로 끌어다 놓기)──▶ NAS \\NAS\출력\실사출력 ──(자동 복사)──▶ 실사 출력 PC  바탕화면\출력받음
                                       NAS \\NAS\출력\레이저   ──(자동 복사)──▶ 레이저 PC     바탕화면\출력받음
```

## 하는 일

- 몇 초마다(기본 5초) NAS 폴더를 확인해 **새 파일·수정된 파일**을 받을 폴더로 복사합니다. 하위 폴더도 그대로.
- **올리는 중인 큰 파일은 기다립니다**: 크기가 두 번 연달아 같아야(=다 올라감) 복사합니다.
- 복사하는 동안은 `이름.part` 로 두었다가 다 되면 이름을 바꿉니다 (반쯤 복사된 파일을 열 일이 없음).
- **NAS 원본은 건드리지 않습니다** (읽기만).
- 같은 이름으로 다시 올리면 **[수정]** 으로 받아 덮어씁니다. 출력 프로그램이 그 파일을 열고 있어 덮어쓸 수 없으면 `이름 (2).pdf` 로 받습니다.
- 받으면 **윈도우 알림** + **알림 소리** (`src/ui/sounds/notify.wav`). **급한 파일**은 같은 소리를 높고 빠르게 세 번 울리는 급한 소리 (`urgent.wav`). 설정에서 두 소리를 들어 볼 수 있고, "확인할 때까지 소리 반복" 을 켤 수 있습니다.
- **소리는 한 번만**: 파일 여러 개가 몇 번에 나눠 들어와도 1분 안에는 다시 울리지 않습니다 (알림 창은 뜸). 급한 파일은 방금 보통 소리가 났어도 급한 소리로 한 번 더 울립니다.
- **모두 확인** 버튼: NEW 표시를 한꺼번에 지웁니다 (줄을 하나씩 누르지 않아도 됨). 출력 완료 체크는 그대로입니다.
- **같은 파일은 두 번 받지 않습니다**: 이름·크기·수정 시각이 같은 파일을 이미 받아 두었으면 NAS 의 하위 폴더를 잠깐 못 읽었다가 다시 읽혀도, '지금 있는 파일 모두 받기' 를 눌러도 또 받지 않습니다. (1.6.0 까지는 NAS 가 잠깐 하위 폴더를 못 읽으면 그 안의 파일을 다시 받는 문제가 있었습니다. 1.7.0 을 켜면 목록에 두 번 들어간 기록을 하나로 합칩니다.)
- **잠깐 끊긴 것은 끊김으로 치지 않습니다**: 와이파이·NAS 가 잠깐 늦게 답하면 2초 뒤 다시 확인하고, 세 번 연달아 안 될 때만 "NAS 연결 끊김" 으로 보이고, 그 뒤로는 30초마다만 다시 확인합니다. 끊긴 까닭(폴더 없음, 권한 없음, 네트워크 응답 없음)도 함께 보여 줍니다.
- 목록: **출력 전 / 출력 완료 / 전체**, 이름 찾기, **열기**, **폴더**(탐색기에서 위치 열기).
- **받은 시각 순서**: 이름 찾기 옆에서 **최신순 / 오래된순** 을 고릅니다 (고른 것은 다음에 켜도 그대로). 출력 전인 급한 파일은 순서와 상관없이 맨 위에 둡니다 (설정에서 끌 수 있음).
- 줄마다 **[출력] 체크칸**: 출력 프로그램에서 열었으면 체크 → "출력 완료 14:20" 처럼 시각이 남고 **출력 전** 목록에서 빠집니다. 잘못 눌렀으면 다시 눌러 풉니다. 나중에 "이거 열었나?" 싶으면 **출력 전** 탭만 보면 됩니다.
- 이 앱의 [열기] 로 열면 "열어봄 14:03" 으로 따로 표시합니다 (열어 본 것 ≠ 출력한 것).
- **까먹은 파일 다시 알림**: 출력 전인 채 30분(설정)이 넘은 파일이 있으면 "출력 안 한 파일 N개" 로 다시 알리고 소리를 냅니다.
- 같은 파일의 새 버전이 오면, 출력 전이던 옛 버전은 **"새 버전으로 바뀜"** 으로 흐리게 두고 출력 전 개수에서 뺍니다 (옛 버전을 잘못 출력하지 않게).
- 처음 온 파일은 노란 **NEW** 표시 (줄을 누르거나 열기·폴더·출력 체크하면 사라짐).
- **규격 표시**: 받은 파일의 크기를 목록에 바로 보여 줍니다. 열어 보지 않고 주문 크기와 맞는지 확인하세요.
  - PDF·AI: `3000×900mm` (재단 크기가 있으면 그것, 5m 넘는 대형 대지도), 여러 쪽이면 `90×50mm · 2쪽`
  - EPS·옛날 AI: 그림 범위 mm
  - JPG·PNG·TIF·PSD: `4724×1417px · 150dpi · 800×240mm`
- **급한 파일**: 파일·폴더 이름에 `[급]` `(급)` `긴급`, 또는 앞뒤가 띄어진 `급` (`급_현수막.pdf`, `현수막_급.pdf`, `급 배너.pdf`) 이 있으면 빨간 **급** 표시, 출력 전 목록 맨 위, 알림 제목에 [급], 급한 소리. `고급명함` 처럼 낱말 속의 '급' 은 급이 아닙니다.
- **NAS 에 출력 완료 표시** (설정에서 켬): 출력 완료로 체크하면 NAS 원본을 그 기계 폴더 안 `_출력완료` 폴더로 옮깁니다 (하위 폴더 그대로). 디자이너는 NAS 만 보고도 출력됐는지 알 수 있습니다. 체크를 풀면 제자리로 돌려놓습니다. 받은 뒤에 NAS 파일이 바뀌었으면(새 버전) 옮기지 않고 알려 줍니다. `_출력완료` 폴더는 받지 않습니다.
- 작업표시줄 오른쪽 **트레이 아이콘**: 파랑(받는 중), 빨간 점(새 파일 있음), 회색(NAS 끊김·멈춤). 마우스를 올리면 출력 전 개수. 창을 닫아도 계속 받습니다. 끝내려면 트레이 아이콘 오른쪽 클릭 → **끝내기**.
- 윈도우 켤 때 자동 실행 (설정에서 끌 수 있음).
- NAS 가 꺼지거나 네트워크가 끊기면 "NAS 연결 끊김" 으로 보이고, 다시 연결되면 이어서 받습니다.
- 처음 켤 때 NAS 에 이미 있던 파일은 받지 않습니다 (옛 파일이 한꺼번에 쏟아지지 않게). 필요하면 설정 → **지금 있는 파일 모두 받기**.
- NAS 가 만드는 시스템 파일(`@eaDir`, `#recycle`, `Thumbs.db`, `.DS_Store` …)과 임시 파일(`~$…`, `.tmp`, `.part`)은 건너뜁니다.
- **받지 않을 확장자** (설정): `psd, zip, mp4` 처럼 쉼표로 적으면 그 종류는 받지 않습니다 (대소문자 상관없음). 나중에 목록에서 빼도 그동안 NAS 에 쌓인 파일은 받지 않고, 그 뒤에 새로 올리거나 바뀐 것만 받습니다.

## 1. NAS 준비 (한 번만)

1. NAS 에 공유 폴더 `출력` 을 만들고, 그 안에 기계별 폴더를 만듭니다. 예: `실사출력`, `레이저`, `UV`, `커팅`.
2. 출력 컴퓨터의 윈도우 탐색기 주소창에 `\\NAS이름` 또는 `\\NAS아이피` (예: `\\192.168.0.10`) 를 넣고 엔터.
   - 시놀로지·큐냅 모두 이 방식(SMB, 윈도우 파일 공유)을 기본으로 켜 두는 경우가 많습니다. 안 열리면 NAS 관리 화면에서 **SMB / 윈도우 파일 서비스** 를 켜세요.
3. 로그인 창이 뜨면 NAS 계정으로 로그인하고 **"자격 증명 기억"** 을 체크합니다 (그래야 컴퓨터를 다시 켜도 자동으로 연결됩니다).
4. `출력\실사출력` 폴더가 열리면 준비 끝. 주소창의 경로(예: `\\192.168.0.10\출력\실사출력`)를 복사해 둡니다.

> 네트워크 드라이브(`Z:`)로 연결해도 되지만, 컴퓨터를 켤 때 드라이브가 늦게 붙으면 잠깐 "연결 끊김" 으로 보일 수 있어 **`\\…` 경로를 권장**합니다.

## 2. 출력 컴퓨터에 설치

1. `BroadFileSync-win32-x64.zip` 을 `C:\BroadFileSync` 같은 곳에 압축을 풉니다 (바탕화면·다운로드 폴더보다 고정된 곳이 좋습니다).
2. 폴더 안의 **`BroadFileSync.exe`** 를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (사내용이라 서명하지 않았습니다).
3. 처음 실행하면 설정 창이 뜹니다.
   - **NAS 폴더**: 1-4 에서 복사한 경로 (예: `\\192.168.0.10\출력\실사출력`) → **연결 확인**
   - **받을 폴더**: 기본 `바탕화면\출력받음` (바꿔도 됨)
   - **저장**
4. 이제 NAS 폴더에 파일을 올려 보세요. 5~10초 안에 알림이 뜹니다.

처음 실행할 때 **시작 메뉴에 "브로애드 파일 받기"** 가 생깁니다 (윈도우는 이게 있어야 알림 창을 띄워 줍니다). 다른 기계도 같은 방법으로 설치하고 NAS 폴더만 그 기계 것으로 정하면 됩니다.

## 설정 항목

| 항목 | 기본값 | |
|---|---|---|
| NAS 폴더 | (없음) | 이 컴퓨터가 받을 기계 폴더 |
| 받을 폴더 | 바탕화면\출력받음 | |
| 확인 간격 | 5초 | 2 ~ 600초 |
| 받으면 소리 | 켬 | |
| 확인할 때까지 소리 반복 | 끔 | 켜면 새 파일 줄을 누를 때까지 6초마다 딩동 |
| 출력 안 한 파일 다시 알림 | 30분 | 출력 전인 채 이만큼 지나면 다시 알림 (0 이면 끔) |
| 출력 완료하면 NAS 원본을 '_출력완료' 폴더로 | 끔 | 켜면 디자이너가 NAS 에서 출력됐는지 볼 수 있음. NAS 계정에 쓰기 권한 필요 |
| 급한 파일은 순서와 상관없이 맨 위에 | 켬 | 끄면 받은 시각 순서대로만 |
| 받지 않을 확장자 | (없음) | 쉼표로 구분. 예: `psd, zip, mp4` |
| 윈도우 켤 때 자동 실행 | 켬 | 켜지면 트레이에만 뜹니다 |
| 처음 켤 때 NAS 에 있던 파일은 받지 않기 | 켬 | |

설정과 받은 기록은 `%APPDATA%\broad-file-sync` 에 있습니다. 받은 기록 목록을 비워도 받은 파일은 지워지지 않습니다.

## 업데이트

새 zip 을 같은 폴더에 덮어 풀고 다시 실행하면 됩니다 (설정·기록은 그대로). 실행 중이면 트레이 → 끝내기 후에 덮어쓰세요.

## 개발

```bash
cd tools/file-sync
npm install
npm start            # 이 컴퓨터에서 실행
npm run icons        # 트레이 아이콘 다시 그리기
npm run package:win  # 윈도우용 만들기 → dist/BroadFileSync-win32-x64
```

| 파일 | 내용 |
|---|---|
| `src/core/sync.js` | 받기 엔진 (NAS 살피기, 다 올라갔는지 확인, 복사, 기록, 급 표시, _출력완료 옮기기) — 전기(Electron) 없이 Node 만으로 동작 |
| `src/core/fileinfo.js` | 파일 규격 읽기 (PDF·AI·EPS mm, JPG·PNG·TIF·PSD 픽셀·dpi) |
| `src/main.js` | 트레이, 알림, 창, 설정 |
| `src/preload.js` | 창에서 쓸 수 있는 기능 목록 |
| `src/ui/` | 목록·설정 화면 |
| `scripts/make-icons.js` | 트레이 아이콘을 코드로 그림 |
| `src/ui/sounds/` | 알림 소리. `notify.wav` 를 바꾸면 `python3 scripts/make-urgent-sound.py` 로 급한 소리도 다시 만듦 |

받기 엔진·규격 읽기 검사: 저장소 맨 위에서 `npm test` (`test/file-sync.test.js`, `test/fileinfo.test.js`). 규격 읽기 견본 파일은 `scripts/make-fixtures.py` 로 만듭니다.
