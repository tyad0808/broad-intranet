# 포토샵 자동 누끼 · 누끼 다듬기

이 폴더에 스크립트가 두 개 있습니다.

| 파일 | 하는 일 |
|---|---|
| `NukkiAuto.jsx` | **배경이 복잡한 사진**에서 사람 + 들고 있는 꽃·소품을 자동으로 골라 누끼 (등신대용) |
| `NukkiRefine.jsx` | 이미 누끼 딴 레이어의 외곽만 다듬기 |

## 자동 누끼 (NukkiAuto.jsx)

1. 사진을 열고 사진 레이어를 고릅니다 (배경 레이어여도 됨).
2. **파일 > 스크립트 > 찾아보기...** 에서 `NukkiAuto.jsx` 를 고르고 **확인**.
3. 결과:
   - `누끼` 레이어 (레이어 마스크로 배경을 가림). 원본은 `원본` 으로 숨겨 둡니다.
   - 문서 옆에 `이름_누끼.png` (투명 배경) — 이걸 일러스트에 놓고 **등신대 패널**을 씁니다.
   - `확인용 배경 (출력 전 끄기)` 분홍 레이어 — 테두리에 초록 잎 등이 남았는지 보기 쉽습니다.
4. 빠지거나 남은 곳은 마스크에 브러시로 고칩니다 (흰색 = 보이기, 검정 = 가리기). 고쳤으면 분홍 배경을 끄고 PNG 를 다시 저장합니다.

| 값 | 기본 | 설명 |
|---|---|---|
| 안쪽으로 축소 | 1 px | 남은 배경 테두리 없애기. 크면 머리카락·꽃 끝이 잘림 |
| 매끄럽게 | 2 px | 울퉁불퉁한 외곽 정리 |

**정확도 높이기:** 포토샵 **환경설정 > 이미지 처리 > 피사체 선택** 을 **클라우드(세부 결과)** 로 두세요 (인터넷 필요). 머리카락·꽃다발이 훨씬 깔끔합니다.
포토샵 2020 이상의 '피사체 선택' 기능을 씁니다. 사람을 못 찾으면 빠른 선택 도구로 직접 고른 뒤 `NukkiRefine.jsx` 를 쓰세요.

## 누끼 다듬기 (NukkiRefine.jsx)

누끼 딴 레이어의 외곽을 **안쪽으로 조금 줄이고 매끄럽게** 다듬어 **레이어 마스크**로 가립니다.
손으로 하던 순서(레이어 썸네일 Ctrl+클릭 → 선택 축소 → 매끄럽게 → 페더 → 레이어 마스크)를 한 번에 합니다.
원본 픽셀은 지우지 않으므로, 마스크를 고치거나 지우면 원래대로 돌아갑니다. 되돌리기(Ctrl+Z) 한 번에 전부 되돌아갑니다.

## 쓰는 법

1. 누끼 딴 레이어 하나를 고릅니다 (배경 레이어·그룹은 안 됨).
2. **파일 > 스크립트 > 찾아보기...** 에서 `NukkiRefine.jsx` 를 고릅니다.
3. 값을 넣고 **확인**.

| 값 | 기본 | 설명 |
|---|---|---|
| 안쪽으로 축소 | 2 px | 외곽을 안쪽으로 줄여 남은 배경 테두리를 없앱니다. 1~2px 부터, 부족하면 늘리세요. 너무 크면 머리카락·손가락 끝이 잘립니다. |
| 매끄럽게 | 3 px | 울퉁불퉁한 외곽 정리 (2~5 추천) |
| 페더 | 0 px | 경계를 부드럽게. **출력용(등신대, 스티커 칼선)은 0** (흐리면 칼선이 지저분해짐) |

넣은 값은 다음에도 기억합니다. 이미 마스크가 있으면 지우고 새로 만들지 묻습니다.

## 메뉴·단축키로 쓰기

`NukkiRefine.jsx` 를 포토샵 설치 폴더의 `Presets\Scripts` 에 넣고 포토샵을 다시 켜면 **파일 > 스크립트** 메뉴에 바로 나옵니다.
**편집 > 단축키** 에서 단축키를 주거나, 액션에 넣어 여러 파일에 돌릴 수 있습니다.

## 참고

'선택 및 마스크' 창의 '가장자리 이동(%)' 대신 **선택 축소(px)** 를 씁니다 (같은 효과, 스크립트로 정확히 되는 방식).
그 다음 등신대는 일러스트 **등신대 패널**(`tools/illustrator-standee`)로 외곽선·칼선을 만듭니다.
