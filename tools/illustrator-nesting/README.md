# 일러스트레이터 네스팅 패널 (용지 폭 · 아크릴 텍스트)

작업물을 용지·원판에 빈틈없이 배치하는 패널 두 개입니다. 브로애드 도구(돔보마크 등)와 따로 설치합니다.
**창 > 확장** 메뉴에 두 패널이 따로 나옵니다.

## 1. 용지 폭 네스팅

롤 용지(예: 폭 1200mm)에 선택한 작업물을 수량만큼 배치해 **쓰는 길이를 최소로** 합니다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| 용지 폭 | 1200mm | 롤 폭 |
| 최대 길이 | 5000mm | 이 길이를 넘으면 다음 장(대지)으로 나눕니다 |
| 용지 여백 | 10mm | 용지 가장자리에서 띄우는 거리 |
| 작업물 사이 간격 | 5mm | |
| 수량 | 1 | 선택한 작업물마다 이만큼 (2개 선택 + 수량 10 → 20개) |
| 90도 돌려서 넣기 | 켬 | |

- 선택한 작업물을 **복제**해 기존 대지 오른쪽에 새 대지(`용지 1`, `용지 2` …)를 만들고 배치합니다. 원본은 그대로입니다.
- 대지 세로는 **실제로 쓴 길이**만큼만 만듭니다. 끝나면 쓴 길이와 용지 효율을 알려 줍니다.
- 크기는 눈에 보이는 범위 기준입니다. 클리핑 마스크는 마스크 모양 기준, 선 두께 포함.
- 배치한 뒤 브로애드 도구의 **돔보 찍기**를 하면 바로 커팅용으로 쓸 수 있습니다.

## 2. 아크릴 텍스트 네스팅

레이저 커팅용으로 글자를 하나씩(또는 조각마다) 떼어 아크릴 원판에 배치합니다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| 원판 가로·세로 | 900 × 600mm | 레이저 작업 영역 또는 아크릴 원판 크기 |
| 원판 여백 | 5mm | |
| 나누기 | 글자 단위 | **글자 단위**: 한 글자씩. **조각 단위**: '한' 의 ㅎ·ㅏ·ㄴ 처럼 떨어진 획마다 따로 → 원판을 더 아낌 |
| 글자 사이 간격 | 3mm | 레이저 커프(타는 폭) + 여유 |
| 세트 수량 | 1 | 같은 글자 세트를 몇 벌 |
| 90도 돌려서 넣기 | 켬 | |
| 레이저 선으로 | 켬 | 면을 없애고 빨강 0.1pt 선으로 |

- 살아있는 글자는 복제본을 **아웃라인**으로 바꿔 씁니다. 그룹은 풀어서 글자마다 나눕니다. 원본은 그대로입니다.
- 원판마다 새 대지(`원판 1`, `원판 2` …)를 만들고 `네스팅` 레이어에 배치합니다. 글자 이름은 `글자_1`, `조각_1` … 입니다.
- 조각 단위에서 'ㅇ', 'ㅁ', 'A' 같은 **구멍은 바깥 획과 함께** 갑니다. 구멍 안의 섬(예: '回' 가운데)은 따로 떨어지는 조각으로 칩니다.
- 크기는 패스 범위 기준(선 두께 제외)입니다.

## 배치 방식과 한계

- 작업물을 **사각형 범위**로 보고 배치합니다. 글자 모양 사이사이(예: 'L' 의 빈 곳)에 다른 글자를 끼워 넣지는 않습니다.
- 정렬 순서와 배치 규칙을 여러 가지로 해 보고 가장 짧은(적은 장수의) 결과를 고릅니다.
  롤은 스카이라인 방식, 원판은 MaxRects 방식입니다.
- 일러스트레이터 작업 영역(약 5.7m) 밖으로 대지를 만들 수 없으면 알려 줍니다. 그럴 땐 새 문서에서 하세요.

## 설치

- 윈도우: `install-windows.bat` 더블클릭
- 맥: 터미널에서 `bash install-mac.sh`

일러스트레이터를 다시 켜고 **창 > 확장 > 용지 폭 네스팅** 또는 **아크릴 텍스트 네스팅** 을 엽니다.

### 패널 없이 쓰기

`jsx` 폴더를 통째로 복사한 뒤 **파일 > 스크립트 > 기타 스크립트...** 에서 `RollNest.jsx` 또는 `TextNest.jsx` 를 고릅니다.

## 파일

| 파일 | 내용 |
|---|---|
| `CSXS/manifest.xml` | 패널 두 개 등록 정보 |
| `roll.html`, `text.html`, `panel.js`, `style.css` | 패널 화면 |
| `jsx/nest-core.jsx` | 배치 계산과 일러스트레이터 작업 (패널·단독 스크립트 공용) |
| `jsx/RollNest.jsx`, `jsx/TextNest.jsx` | 패널 없이 쓰는 단독 스크립트 |

배치 계산과 조각 나누기는 `test/nesting.test.js` 에서 검사합니다 (`npm test`).
