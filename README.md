# 브로애드 인트라넷

여러 판매 채널의 주문, 제작 작업 공유, 알림을 한 곳에서 처리하는 사내 인트라넷입니다.
견적 계산기(`naver-smartstore-api`)와는 별개의 프로젝트입니다.

## 처음 실행하기

```bash
npm install            # 필요한 패키지 설치
cp .env.example .env   # 설정 파일 만들기 → .env 를 열어 값 채우기
npm run dev            # 개발 모드 실행 (코드를 고치면 자동 재시작)
```

브라우저에서 http://localhost:3000 을 엽니다.

## 첫 관리자 계정 만들기

```bash
npm run create-admin
```

이메일, 이름, 비밀번호를 차례로 입력합니다. 비밀번호는 입력해도 화면에 보이지 않습니다.
이미 가입된 이메일을 넣으면 그 계정이 관리자 + 승인 상태로 바뀝니다.

## 주문 수집

서버를 켜면 바로 한 번, 이후 `COLLECT_INTERVAL_MINUTES`(기본 5분)마다 주문을 가져옵니다.
관리자 메뉴 → **주문 수집** 탭에서 수집 기록을 보고 **지금 수집** 버튼으로 바로 가져올 수 있습니다.

| `.env` 의 `ORDER_SOURCE` | 동작 |
|---|---|
| `mock` (기본) | 가짜 주문. 개발·연습용 |
| `naver` | 실제 스마트스토어. 네이버 커머스 API센터에 **등록된 서버 IP** 에서만 동작 |

네이버 API 는 `src/channels/naverClient.js` 의 허용 목록에 있는 **조회용 주소 2개만** 호출할 수 있습니다.
판매자센터에서 발주확인한 주문은 인트라넷 카드가 '발주' → '발주확인' 단계로 자동으로 옮겨집니다.

## 시안 컨펌

상단 **시안** 메뉴에서 시안 이미지를 올리면 고객에게 링크 문자가 갑니다. 고객은 로그인 없이 휴대폰으로 링크를 열어
**확정** 하거나, 그림에서 고칠 곳을 눌러 번호를 찍고 **수정 요청** 을 보냅니다.

- 주문을 연결하면 고객 이름·전화번호가 자동으로 채워지고, 주문 카드가 단계를 따라 움직입니다.
  시안 보냄 → **컨펌**, 고객 확정 → **제작**, 수정 요청 → **디자인작업**
- 수정 시안(2차, 3차 …)은 같은 링크에 쌓이고, 고객은 이전 시안도 볼 수 있습니다.
- 고객이 확정하거나 수정을 요청하면 인트라넷 알림이 남고, `PROOF_NOTIFY_PHONES` 번호로 문자가 갑니다.
- 출력 파일 변환은 확정 뒤 디자이너가 직접 합니다. (이 기능은 파일을 NAS 로 옮기지 않음)
- 시안 이미지는 `data/proofs/` 에 저장됩니다. 백업할 때 `data/` 폴더를 통째로 복사하세요.

| `.env` 의 `SMS_DRIVER` | 동작 |
|---|---|
| `mock` (기본) | 문자를 보내지 않고 시안 화면의 '보낸 문자' 에 기록만 남김. 개발·연습용 |
| `aligo` | 알리고로 실제 발송. `ALIGO_API_KEY`, `ALIGO_USER_ID`, `ALIGO_SENDER` 필요. 알리고에 **이 서버의 IP** 를 등록해야 함 |

`PUBLIC_BASE_URL` 에 고객이 접속할 실제 주소(예: `https://intranet.도메인`)를 넣어야 문자 속 링크가 맞게 나갑니다.
90바이트(한글 약 45자)가 넘는 문자는 장문(LMS)으로 보냅니다. 링크가 들어가면 보통 장문입니다.

## 비밀값 관리

- API 키와 비밀번호는 `.env` 에만 넣습니다. `.env` 는 `.gitignore` 에 들어 있어 깃에 올라가지 않습니다.
- `.env.example` 은 필요한 항목 이름만 적힌 견본입니다. 진짜 값을 넣지 마세요.

## 1차 범위의 안전 원칙

1차에서는 스마트스토어 주문을 **조회만** 합니다. 발주확인·발송처리 등 주문 상태를 바꾸는 네이버 API는 호출하지 않습니다.
인트라넷 안의 작업 상태(발주확인, 디자인작업 등)는 사내 기록일 뿐 네이버에 전달되지 않습니다.
