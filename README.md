# 브로애드 인트라넷

여러 판매 채널의 주문, 제작 작업 공유, 알림을 한 곳에서 처리하는 사내 인트라넷입니다.
견적 계산기(`naver-smartstore-api`)와는 별개의 프로젝트입니다.

## 처음 실행하기

```bash
npm install            # 필요한 패키지 설치
cp .env.example .env   # 설정 파일 만들기 → .env 를 열어 값 채우기
npm run dev            # 개발 모드 실행 (코드를 고치면 자동 재시작)
```

브라우저에서 http://localhost:3000 을 엽니다.

## 첫 관리자 계정 만들기

```bash
npm run create-admin
```

이메일, 이름, 비밀번호를 차례로 입력합니다. 비밀번호는 입력해도 화면에 보이지 않습니다.
이미 가입된 이메일을 넣으면 그 계정이 관리자 + 승인 상태로 바뀝니다.

## 주문 수집

서버를 켜면 바로 한 번, 이후 `COLLECT_INTERVAL_MINUTES`(기본 5분)마다 주문을 가져옵니다.
관리자 메뉴 → **주문 수집** 탭에서 수집 기록을 보고 **지금 수집** 버튼으로 바로 가져올 수 있습니다.

| `.env` 의 `ORDER_SOURCE` | 동작 |
|---|---|
| `mock` (기본) | 가짜 주문. 개발·연습용 |
| `naver` | 실제 스마트스토어. 네이버 커머스 API센터에 **등록된 서버 IP** 에서만 동작 |

네이버 API 는 `src/channels/naverClient.js` 의 허용 목록에 있는 주소 4개(조회 2개 + 발주확인·발송처리)만 호출할 수 있습니다.
판매자센터에서 발주확인한 주문은 인트라넷 카드가 '발주' → '발주확인' 단계로 자동으로 옮겨집니다.

## 발주확인·발송처리 (2차)

- 주문 카드의 **스마트스토어 처리** 칸에서 발주확인 → 송장 입력 → 발송처리. 누를 때마다 확인창이 뜹니다.
- 목록에서 여러 주문을 체크해 **선택 발주확인 / 선택 발송처리…** 로 한꺼번에 처리할 수 있습니다 (최대 50건).
- 배송 방법: 택배(로젠·경동) / 퀵서비스 / 직접전달. 택배사 목록은 `src/channels/shipping.js` 에서 바꿉니다.
- 누가·언제·무엇을 했는지는 주문 카드의 **처리 기록**과 관리자 메뉴 → **처리 기록** 탭에 남습니다.
- 고객이 취소·반품·교환을 요청하면 카드에 빨간 표시가 붙고, 관리자와 담당자에게 알림이 갑니다.
  요청 중인 상품은 발주확인·발송처리를 막아 둡니다 (판매자센터에서 먼저 처리).

| `.env` 의 `NAVER_WRITE` | 동작 |
|---|---|
| `off` (기본) | **연습 모드.** 버튼은 동작하지만 네이버로 보내지 않고 기록만 남김 |
| `on` | 실제로 네이버에 보냄 (`ORDER_SOURCE=naver` 일 때만) |

## 실시간 반영과 알림

- 누가 주문의 담당자·작업 단계를 바꾸면 다른 직원의 주문 목록이 새로고침 없이 바뀝니다.
- 수기 주문: 목록의 **＋ 수기 주문** 으로 계좌이체·전화 주문을 직접 등록 (입금 확인 → 발송 완료 기록 → 취소·수정). 바깥으로는 아무것도 보내지 않음
- 알림 4종: **신규 발주**(전 직원), **미지정 초과**(관리자 + 지정 직원, 해소될 때까지 반복), **가입 신청**(관리자), **취소·반품·교환 요청**(관리자 + 담당자)
- 화면 알림 + 소리. 상단 **알림 켜기**를 누르면 다른 창을 보고 있어도 브라우저 알림이 뜹니다.
- 미지정 기준 건수·반복 간격·받는 사람은 관리자 메뉴 → **알림 설정**에서 바꿉니다.
- 운영 서버의 Caddy(HTTPS)는 실시간 소식(`/events`)을 모아 두지 않고 바로 전달하므로 따로 설정할 것이 없습니다.

## 운영 서버

설치·업데이트·백업 방법은 [deploy/DEPLOY.md](deploy/DEPLOY.md) 를 보세요.
운영 서버(`NODE_ENV=production`)에서는 가짜 주문을 쓸 수 없고, 네이버 키를 넣기 전에는 `ORDER_SOURCE=off` 로 둡니다.

## 비밀값 관리

- API 키와 비밀번호는 `.env` 에만 넣습니다. `.env` 는 `.gitignore` 에 들어 있어 깃에 올라가지 않습니다.
- `.env.example` 은 필요한 항목 이름만 적힌 견본입니다. 진짜 값을 넣지 마세요.

## 1차 범위의 안전 원칙

1차에서는 스마트스토어 주문을 **조회만** 합니다. 발주확인·발송처리 등 주문 상태를 바꾸는 네이버 API는 호출하지 않습니다.
인트라넷 안의 작업 상태(발주확인, 디자인작업 등)는 사내 기록일 뿐 네이버에 전달되지 않습니다.
